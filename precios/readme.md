# 📊 Estimación de Precios de Alimentos

Este directorio contiene herramientas interactivas diseñadas para el cálculo dinámico y la proyección de costos de productos básicos. Estas páginas utilizan tablas automáticas para facilitar la actualización de valores y el desglose de precios.

---

## 🛠️ Calculadoras Disponibles

| Recurso | Descripción | Acceso Directo |
| :--- | :--- | :--- |
| **Control de Carnes** | Herramienta para el cálculo por kilogramo, cortes específicos y rendimiento de piezas. | [carnes.html](carnes.html) |
| **Control de Huevos** | Estimación de costos por unidad, media docena y cartones completos. | [huevos.html](huevos.html) |

---

## 📝 Detalles de las Herramientas

### 🥩 Carnes (`carnes.html`)
Esta aplicación permite gestionar los precios fluctuantes de distintos cortes. 
* **Funcionalidad**: Cálculo automático basado en el peso ingresado.
* **Uso**: Ideal para comparar precios entre proveedores o calcular el costo total de pedidos grandes.

### 🥚 Huevos (`huevos.html`)
Optimizado para la gestión de inventario y costos de este producto esencial.
* **Funcionalidad**: Conversión automática de precios entre unidades sueltas y empaques cerrados.
* **Uso**: Útil para determinar el ahorro por volumen de compra.

---

## ⚙️ Instrucciones de Uso
1. Navega a la herramienta deseada haciendo clic en los enlaces de la tabla superior.
2. Ingresa los valores actualizados en los campos de entrada de la tabla.
3. Los totales y estimaciones se actualizarán automáticamente sin necesidad de recargar la página.

> [!TIP]
> Puedes descargar estas páginas para usarlas de forma local en tu dispositivo sin necesidad de conexión a internet, ya que toda la lógica de cálculo reside en el archivo HTML.
