¿Qué hace esta herramienta?

Imagina que tienes una foto satelital gigante que quieres descargar, pero tu ordenador o la herramienta solo te permite bajar un trozo pequeño a la vez. Esta aplicación calcula matemáticamente cuál es el tamaño máximo del cuadrado que puedes bajar sin exceder el límite de datos. Luego, dibuja una cuadrícula (como un tablero de ajedrez) sobre tu mapa para que sepas exactamente cómo dividirlo en trozos manejables.

Análisis Geométrico

La aplicación trabaja con dos elementos geométricos clave:

1. Bounding Box (Caja Delimitadora): Al cargar tu archivo, la app encuentra el rectángulo mínimo que cubre toda tu área de interés.
2. Retícula (Fishnet): Divide esa caja en cuadrados iguales. El tamaño de cada cuadrado se calcula usando la fórmula: Lado = √(Límite de Píxeles / Bandas) × Resolución.

1. El problema: Área excesiva
2. El cálculo: Lado máximo
3. La solución: Retícula
Datos y Requerimientos

Datos de entrada:
- Límite de píxeles (Ej: 5,000,000).
- Número de bandas espectrales (Ej: 7 para Landsat).
- Resolución espacial (Metros por píxel).
- Archivo georreferenciado: GeoJSON o GeoTIFF.

Requerimientos Técnicos:
- Navegador web moderno (Chrome, Firefox, Edge).
- Conexión a Internet (para cargar la librería de lectura GeoTIFF).
- El archivo GeoTIFF debe tener cabeceras geográficas válidas.
